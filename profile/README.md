# OpenARI

Independent open-source tools for Apple Reference Image.

We are building a shared verification engine, command-line tools, and language
libraries for applications that accept images. Security, explicit version
support, and predictable resource use guide the implementation.

**Current status:** planning and development scaffold. No Apple ARI format
revision is supported yet. OpenARI cannot authenticate uploads today.
